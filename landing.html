About the Platform

What is QA Lab?

QA Lab is a self-contained static website designed specifically as a training ground for end-to-end automation engineers. Every page is a scenario, every scenario is a challenge.

🟣
Progressive Difficulty

Start with a simple login form, work up to nested iFrames, Shadow DOM, race conditions, and canvas interactions.

🟢
Zero Dependencies

Pure HTML, CSS, and Vanilla JavaScript. No npm, no build step, no Docker. Open index.html and start automating.

🔵
Automation First Design

Every interactive element has a stable data-testid attribute. Full ARIA support enables getByRole() queries.

🟡
GitHub Copilot Integration

Every page includes a ready-to-copy Copilot prompt. Select your framework, copy, and paste into Copilot Chat to instantly generate tests.

🔴
Intentional Pitfalls

Some pages intentionally contain dynamic IDs, timing issues, and bad selectors — so engineers practice robust locator strategies.

scenario-17-shadow-dom.spec.ts
// Playwright auto-pierces open shadow roots
test('shadow login form', async ({ page }) => {
  await page.goto('pages/17-shadow-dom.html');

  // Pierce shadow DOM automatically
  const login = page.locator('qa-login');
  await login.locator('[data-testid="shadow-input-email"]')
    .fill('test@example.com');
  await login.locator('[data-testid="shadow-btn-submit"]')
    .click();

  await expect(page.getByTestId('shadow-login-result'))
    .toBeVisible();
});

Built-in Copilot Integration

Generate tests with GitHub Copilot

Every scenario page includes a structured markdown prompt ready for Copilot Chat. Select your target framework and get a complete, production-ready test file generated in seconds.

1
Open any scenario page and scroll to the Copilot Prompt section at the bottom.
2
Select your framework from the dropdown: Playwright, Selenium, Cypress, Robot Framework, or WebdriverIO.
3
Click Copy Prompt, open Copilot Chat in VS Code (Ctrl+Alt+I), and paste.
4
Copilot generates a complete test file with all scenarios, proper waits, and your chosen framework's conventions.
