🟣 Atomic Reproduction Steps

🟢 Playwright Pierce Shadow with Locator

// Method 1: direct pierce (Playwright auto-pierces open shadow)
await page.locator('qa-login').locator('#shadow-email').fill('test@test.com');
await page.locator('qa-login').locator('#shadow-password').fill('pass123');
await page.locator('qa-login').locator('#shadow-btn-submit').click();

// Method 2: getByTestId within shadow host
const loginComponent = page.locator('[data-testid="shadow-login"]');
await loginComponent.locator('[data-testid="shadow-input-email"]').fill('test@test.com');

// Nested:
const outer = page.locator('qa-outer');
const inner = outer.locator('qa-inner');
await inner.locator('#nested-input').fill('nested value');

🟡 Pitfalls

  • Playwright auto-pierces open shadow roots with standard locator().
  • Cypress requires the cypress-shadow-dom plugin for shadow piercing.
  • Selenium can pierce shadow with JS: element.shadowRoot.querySelector(...).
  • Closed shadow roots ({ mode: 'closed' }) cannot be accessed from outside.
