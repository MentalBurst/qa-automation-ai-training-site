🟣 Atomic Reproduction Steps

🟢 Scenario A Wait for Spinner to Disappear

  1. Assert loading-spinner-area is not visible
  2. Click btn-load-data
  3. Assert loading-spinner-area is visible
  4. Wait for loading-spinner-area to be hidden (timeout: 5000ms)
  5. Assert loaded-content is visible
  6. Assert async-table-body contains at least 3 rows

🟢 Scenario B Retry Test

  1. Click btn-retry-start
  2. Wait for retry attempt logs to appear
  3. Assert attempt 1 and 2 show failure status
  4. Assert attempt 3 shows success status
  5. Assert retry-success is visible

🟢 Scenario C Sequential Element Wait

  1. Click btn-start-delayed
  2. Wait for delayed-el-1 to be visible (500ms)
  3. Wait for delayed-el-2 to be visible (1500ms)
  4. Wait for delayed-el-3 to be visible (3000ms)
  5. Assert delayed-final-btn is visible
  6. Click delayed-final-btn

🟡 Pitfalls

  • Never use fixed sleep always use waitForSelector or waitFor.
  • Spinner and content share the same container assert both states explicitly.
  • Retry logs are added dynamically use waitFor on the attempt element.
