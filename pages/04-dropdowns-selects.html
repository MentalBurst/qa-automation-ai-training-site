🔵 Test Objective

  • Select option from native <select>
  • Select multiple from multi-select
  • Open custom dropdown, click option
  • Assert hidden input value after selection

🔵 Key Selectors

// Native selects:
page.selectOption('#select-country', 'pt')
page.selectOption('#select-skills', ['js','ts'])

// Custom dropdown:
getByTestId('custom-dropdown-trigger')
getByTestId('dd-option-python')
getByTestId('custom-dropdown-hidden')
  // .inputValue() → 'python'

🟡 Challenges

  • Custom dropdown is a <ul> list NOT a native select
  • Assert value from hidden input, not visible label

🟣 Atomic Reproduction Steps

🟢 Scenario A Native Select

  1. Navigate to pages/04-dropdowns-selects.html
  2. Assert #select-country has a default empty option selected
  3. Select "Portugal" from select-country
  4. Assert selected value is "pt"
  5. Click btn-read-selects
  6. Assert select-output contains "pt"

🟢 Scenario B Custom Dropdown

  1. Assert custom-dropdown-list is not visible
  2. Click custom-dropdown-trigger
  3. Assert custom-dropdown-list is now visible
  4. Assert trigger has aria-expanded="true"
  5. Click dd-option-python
  6. Assert list is closed
  7. Assert custom-dropdown-value text is "Python"
  8. Assert hidden input value is "python"

🟡 Pitfalls

  • Do NOT use selectOption() on the custom dropdown it's not a native select.
  • The custom dropdown closes on outside click test keyboard navigation separately.
  • Multi-select requires Ctrl+click in real interaction, but selectOption() in Playwright accepts arrays.
