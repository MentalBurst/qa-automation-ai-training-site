🟣 Atomic Reproduction Steps

🟢 Scenario A Open & Close Info Modal

  1. Assert #modal-info has class "hidden"
  2. Click btn-open-info-modal
  3. Assert #modal-info does NOT have class "hidden"
  4. Assert modal-info-title text is "Information"
  5. Click btn-close-info-modal (✕)
  6. Assert #modal-info has class "hidden"

🟢 Scenario B Confirm Modal Yes/No

  1. Click btn-open-confirm-modal
  2. Assert modal is visible
  3. Click btn-modal-confirm-yes
  4. Assert modal is now hidden
  5. Assert confirm-result is visible and contains "confirmed"
  6. Repeat test clicking "No" assert result contains "cancelled"

🟢 Scenario C Toast Auto-dismiss

  1. Click btn-toast-success
  2. Assert a toast with data-testid="toast-success" appears
  3. Wait 5 seconds
  4. Assert toast is no longer in DOM

🟡 Pitfalls

  • Modals use class="hidden" not display:none check for class presence.
  • Focus should move to modal on open assert focused element is inside modal.
  • Body scroll is locked when modal is open verify overflow:hidden on body.
  • Persistent toast has no auto dismiss must click close button manually.
