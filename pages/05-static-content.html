🟣 Atomic Reproduction Steps

🟢 Scenario A Heading & Text Assertions

  1. Navigate to pages/05-static-content.html
  2. Assert page title is "05 Static Content Verification | QA Lab"
  3. Assert main-heading text is "Static Content Verification"
  4. Assert para-intro contains "20 progressive scenarios"
  5. Assert blockquote-1 is visible
  6. Assert quote-author text contains "QA Lab Team"

🟢 Scenario B Stat Card Assertions

  1. Assert stat-tests-value text is "1,248"
  2. Assert stat-passed-value text is "1,199"
  3. Assert stat-failed-value text is "49"
  4. Assert stat-coverage-value text is "94.2%"

🟢 Scenario C Link Attribute Assertions

  1. Assert link-external has attribute target="_blank"
  2. Assert link-external has attribute rel containing "noopener"
  3. Assert link-disabled has aria-disabled="true"
  4. Assert link-to-login href ends with "01-simple-login.html"

🟢 Scenario D Table Content Assertions

  1. Assert static-table-body has 5 rows
  2. Assert first row (row-playwright) cell cell-playwright-name text is "Playwright"
  3. Assert cell-playwright-status has class "badge-beginner"
  4. Assert cell-playwright-lang contains "TypeScript"

🟡 Pitfalls

  • The broken image renders a broken icon the DOM element still exists and is visible.
  • Stat numbers contain commas ("1,248") use toContainText or exact match carefully.
  • Don't rely on pixel position for static content always use text matchers.
