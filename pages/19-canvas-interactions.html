🔵 Test Objective

  • Draw on canvas using mouse events
  • Read pixel color after drawing
  • Click exact canvas coordinates
  • Assert zone result text

🔵 Playwright Code

const canvas = page.locator('#drawing-canvas');
const box = await canvas.boundingBox();

// Draw a line
await page.mouse.move(box.x + 50, box.y + 50);
await page.mouse.down();
await page.mouse.move(box.x + 200, box.y + 150);
await page.mouse.up();

// Click zone at coordinates
await canvas.click({ position: { x: 75, y: 100 } });

// Read pixel via evaluate
const pixel = await page.evaluate(() => {
  const c = document.getElementById('zones-canvas');
  const ctx = c.getContext('2d');
  return ctx.getImageData(75, 100, 1, 1).data;
});

🟣 Atomic Reproduction Steps

🟢 Scenario A Draw and Verify Stroke

  1. Get bounding box of #drawing-canvas
  2. Move mouse to canvas coordinates (50, 50)
  3. Press mouse button down
  4. Drag to (200, 150)
  5. Release mouse button
  6. Assert canvas-stroke-count incremented
  7. Optionally: read pixel at drawn coordinates verify non-white

🟢 Scenario B Click Zone

  1. Click #zones-canvas at position { x: 75, y: 100 } (Zone A)
  2. Assert zone-result contains "Zone A"
  3. Assert zone-click-count incremented to 1

🟡 Pitfalls

  • Canvas has NO built-in accessibility all interaction must use mouse coordinates.
  • Canvas bounding box changes if window is resized always re-query before interacting.
  • Screenshot-based visual testing is the most reliable way to assert canvas content.
  • Pixel reading via getImageData requires the canvas to be same-origin (no CORS).
