🟣 Atomic Reproduction Steps

🟢 Scenario A Sortable List Reorder

  1. In Playwright: use drag(source, target) or dragAndDrop(from, to)
  2. Drag sort-item-3 to position above sort-item-1
  3. Click btn-read-order
  4. Assert sort-order-output shows item 3 in position 1

🟢 Scenario B Kanban Card Transfer

  1. Assert count-todo is "3"
  2. Drag kanban-card-1 to zone-done
  3. Assert kanban-card-1 is now inside zone-done
  4. Assert count-done is "2"
  5. Assert count-todo is "2"

🟡 Pitfalls

  • HTML5 drag events use dataTransfer Playwright's dragAndDrop() handles this correctly but custom libraries may not.
  • In Selenium, drag and drop with Actions class may differ from native HTML5 DnD.
  • Assert the destination container's children, not element position.
