Nested iFrames

Two levels of same-origin iframes, each with interactive forms and buttons. Practice frameLocator() chaining.

The outer page contains Frame A. Frame A contains Frame B (nested). Each frame has its own form and interactive elements.

🟣 Atomic Reproduction Steps

🟢 Scenario A Outer Page Interaction

  1. Navigate to pages/16-nested-iframes.html
  2. Fill outer-input with "Hello outer"
  3. Click btn-outer-submit
  4. Assert outer-result-text contains "Hello outer"

🟢 Scenario B Frame A Interaction (Playwright)

  1. Get frameLocator('#iframe-a')
  2. Fill #frame-a-input with "Frame A data"
  3. Click #btn-frame-a-submit
  4. Assert #frame-a-result contains "Frame A data"

🟢 Scenario C Nested Frame B (Playwright)

  1. Chain: frameLocator('#iframe-a').frameLocator('#iframe-b')
  2. Fill #frame-b-input with "Deeply nested!"
  3. Click #btn-frame-b-submit
  4. Assert #frame-b-result is visible with the correct text

🟡 Pitfalls

  • iFrames require frameLocator() in Playwright regular locators will NOT find elements inside frames.
  • In Selenium: use driver.switchTo().frame('frame-a') then switchTo again for frame-b.
  • Always switch BACK to default content after working inside a frame.
  • Cross-origin iframes would require additional configuration these are same-origin.
