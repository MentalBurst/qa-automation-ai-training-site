File Upload

Drag-and-drop dropzone, multi-file input, type/size validation, simulated upload progress, preview and remove files.

A. Drag & Drop Dropzone

🟡

Drop files here or click to select

Accepted: JPG, PNG, PDF, TXT Max 5MB each Up to 5 files

🟢

All files uploaded successfully!

B. Simple File Input (single file)

Images only (JPG, PNG, GIF, WebP). Max 2MB.

🔵 Test Objective

  • Upload valid file → appears in list
  • Upload wrong type → error shown
  • Upload oversized → error shown
  • Click Upload → progress animates → success
  • Remove file → disappears from list

🔵 Playwright Code

// Set file on hidden input:
await page.setInputFiles(
  '#file-input',
  'path/to/test-file.pdf'
);

// Assert file in list:
await page.getByTestId(
  'file-item-test-file.pdf'
).toBeVisible();

// Click upload:
await page.getByTestId('btn-upload').click();

// Wait for success:
await page.getByTestId(
  'upload-success'
).toBeVisible();

🟣 Atomic Reproduction Steps

🟢 Scenario A Valid File Upload

  1. Use setInputFiles('#file-input', 'sample.pdf')
  2. Assert a file entry with name "sample.pdf" appears in file-list
  3. Assert upload-actions is visible
  4. Click btn-upload
  5. Assert progress bars animate (check CSS width > 0)
  6. Wait for upload-success to be visible (simulated 2s)

🔴 Scenario B Invalid File Type

  1. Use setInputFiles('#file-input', 'malware.exe') via JS injection
  2. Assert file-errors is visible
  3. Assert error contains "not allowed"

🟡 Pitfalls

  • The hidden file input accepts the setInputFiles call even though it is visually hidden.
  • Upload progress is simulated don't wait for real network; wait for the success element.
  • Image preview uses FileReader only works in browser context, not in Node.js.
