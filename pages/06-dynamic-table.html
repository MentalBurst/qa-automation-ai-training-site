🟣 Atomic Reproduction Steps

🟢 Scenario A Sort by Name Ascending

  1. Navigate to pages/06-dynamic-table.html
  2. Assert table has 10 rows visible (default page size)
  3. Click th-name column header once
  4. Assert th-name has aria-sort="ascending"
  5. Assert first visible row name comes before last row name alphabetically
  6. Click th-name again
  7. Assert th-name has aria-sort="descending"

🟢 Scenario B Search Filter

  1. Type "admin" into table-search
  2. Assert only rows where name or role contains "admin" are shown
  3. Assert table-info reflects filtered count
  4. Clear the search input
  5. Assert all rows reappear

🟢 Scenario C Row Selection & Delete

  1. Click checkbox on row 1
  2. Assert btn-delete-selected becomes enabled
  3. Click checkbox on row 2
  4. Click btn-delete-selected
  5. Assert those 2 rows no longer appear in the table
  6. Assert table-info count decreased by 2

🟡 Pitfalls

  • Row indices change after sorting/filtering use data-row-id not position.
  • Pagination re-renders rows stable IDs are on cells, not tr index.
  • Delete confirmation modal must be accepted before rows disappear.
