🟣 Atomic Reproduction Steps

🟢 Scenario A Role-based Locators

  1. Use page.getByRole('button', { name: 'Toggle Details' })
  2. Click it
  3. Assert button now has aria-expanded="true"
  4. Assert expandable-region is visible
  5. Use page.getByRole('region', { name: 'Polite announcements' })

🟢 Scenario B Focus Trap

  1. Click btn-open-focus-trap
  2. Assert modal-focus-trap is visible
  3. Assert focus is on first focusable element (trap-input-1)
  4. Press Tab 3 times assert focus stays within modal
  5. Press Escape assert modal is closed

🟡 Key A11y Tips

  • Use getByRole() over getByTestId() when testing accessibility specifically.
  • Live regions announce changes asynchronously wait for text content to update.
  • axe-core integration: import { checkA11y } from 'axe-playwright'.
  • Always verify that keyboard navigation matches visual tab order.
