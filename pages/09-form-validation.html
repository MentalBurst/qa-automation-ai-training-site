🟣 Atomic Reproduction Steps

🟢 Scenario A Debounced Username Check

  1. Type "adm" in input-username
  2. Assert username-checking is NOT yet visible (debounce pending)
  3. Type "in" (completing "admin") and wait 700ms
  4. Assert username-checking becomes visible
  5. Wait for check to complete (simulated 1.2s)
  6. Assert username-taken is visible
  7. Clear field, type "uniqueuser99" and wait 1.5s
  8. Assert username-available is visible

🟢 Scenario B Conditional Fields

  1. Assert business-fields is not visible
  2. Select "Business" from select-account-type
  3. Assert business-fields is now visible
  4. Assert input-company is required
  5. Select "Personal" from select-account-type
  6. Assert business-fields is hidden again
