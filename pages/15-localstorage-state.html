🟣 Atomic Reproduction Steps

🟢 Scenario A Cart Persistence

  1. Click btn-add-playwright
  2. Assert cart-count is "1"
  3. Assert cart-total text is "$49"
  4. In Playwright: read localStorage page.evaluate(() => localStorage.getItem('qalab_cart'))
  5. Reload the page
  6. Assert cart is restored cart-count still "1"

🟢 Scenario B Preferences Persist

  1. Select "Português" from pref-language
  2. Check pref-notifications
  3. Click btn-save-prefs
  4. Assert prefs-saved-msg is visible
  5. Reload the page
  6. Assert pref-language still shows "Português"
  7. Assert pref-notifications is still checked

🟡 Pitfalls

  • LocalStorage is NOT cleared between test runs by default always set initial state with evaluate.
  • Use page.evaluate(() => localStorage.clear()) in test setup.
  • Notes IDs are timestamps don't assert by ID, assert by text content.
