  • Check/uncheck individual checkboxes
  • Verify select-all sets indeterminate state
  • Select radio options; verify mutual exclusion
  • Toggle switches; verify aria-checked attribute

🟡 Challenges

  • Indeterminate state: not a standard HTML attribute must use JS property
  • Toggle switches use CSS + JS assert aria-checked

🟣 Atomic Reproduction Steps

🟢 Scenario A Select All then Deselect One

  1. Navigate to pages/03-checkboxes-radios.html
  2. Assert selection-count text is "0 of 5 selected"
  3. Click cb-select-all
  4. Assert selection-count text is "5 of 5 selected"
  5. Assert all group items are checked
  6. Click cb-item-2 to deselect it
  7. Assert cb-select-all has indeterminate state (JS property)
  8. Assert selection-count text is "4 of 5 selected"

🟢 Scenario B Radio Mutual Exclusion

  1. Assert radio-mid is checked by default
  2. Click radio-junior
  3. Assert radio-junior is checked
  4. Assert radio-mid is NOT checked
  5. Assert radio-senior is NOT checked

🟡 Pitfalls

  • The indeterminate state is a JavaScript property, not an HTML attribute use evaluate(el => el.indeterminate) in Playwright.
  • Disabled inputs cannot be interacted with assert they are disabled before clicking.
  • Pre-checked #cb-newsletter ensure your test doesn't assume unchecked state.
